# Plataforma de Gestión de Inventario y Ventas (tipo mini ERP-CoffeBexa)

Modern management dashboard for retail and coffee shop operations.

## Technologies
- Frontend UI
- TypeScript
- Tailwind CSS
- Backend API Service

## Features
- Authentication
- Inventory management
- Customer management
- Analytics dashboard
- Role-based permissions
